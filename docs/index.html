Managed Pressure Drilling Intelligence

The Wellbore Speaks.

The pressure window is narrow. The data is contaminated by connection artifacts, pipe-squat transients, and flow regime changes. Correlations that held at 8,000 feet break at 12,000. This platform separates physics from noise — distinguishing a genuine ECD excursion from a post-connection pressure recovery, tracking when channel relationships deviate from what the formation and fluid column predict.

Enter the Platform → Source Code
Artifact Discrimination
The architecture identifies connection transients and isolates them from operational signal. Settle time measured per channel per transition type.
Post-connection ROP spikes are pipe-squat artifacts — the drillstring compresses under resumed WOB. The settle time varies by BHA configuration, not by depth.
Deviation Detection
Channel behavior compared against computed profiles per rig state. The system flags when correlations break or values contradict the detected state.
When SPP rises 15% above its DRILLING profile while ROP drops, the system doesn't flag either channel alone — it flags the divergence between them.
Relationship Tracking
Pairwise channel correlations computed within each operational state. When WOB-torque decouples from its drilling profile, the architecture reports what changed.
WOB-torque correlation of 0.91 during normal drilling. When it drops to 0.12 at the same depth interval, either the formation changed or the bit is failing. The data knows which.
State-Aware Computation
Every statistic conditioned on rig state. A channel's range during DRILLING is a different number than during CONNECTION. The system distinguishes which one applies.
SPP during DRILLING: 2,400–2,900 psi. SPP during CONNECTION: 0–50 psi. A “normal” pressure depends entirely on what the rig is doing. The system always knows.

Three Layers

See. Alert. Investigate.

Domain knowledge surfaces through three consumption layers across 11 analysis pages. Same data, different depths of engagement. A rig hand sees state bands. A drilling engineer investigates channel relationships across a 1,000-foot interval.

Layer 1 — Passive

Annotations

State bands colored by rig activity. Validity shading dims non-informative data. Artifact markers at state transitions. Health indicators compare current values against computed profiles. Passive by design — no interaction required.

SPP state band: DRILLING=teal, CONNECTION=amber Validity: pumps_off → dim SPP, ROP, torque
Layer 2 — Active

Alerting

Transition anomaly: settle time exceeds 2x the computed average. Relationship break: a correlation that held in DRILLING inverts or drops. State inconsistency: channel values contradict the detected rig state for more than 30 seconds.

ALERT: WOB-TORQ correlation 0.91→0.12 at 9,400 ft Type: RELATIONSHIP_BREAK | State: DRILLING
Layer 3 — Interactive

Investigation

Point query: what is happening at this depth? Channel query: tell me everything about this channel. Interval query: summarize this 500-foot section. Structured responses with optional LLM narrative synthesis via local model.

QUERY: “What happened at 8,247 ft?” → TORQ out_of_range for DRILLING state → All other channels normal
