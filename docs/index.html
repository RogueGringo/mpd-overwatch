Three Layers

See. Alert. Investigate.

Domain knowledge surfaces through three consumption layers on all 10 analysis pages. Same data, different depths of engagement. A rig hand sees state bands. A drilling engineer investigates channel relationships across a 1,000-foot interval.

ARTWORK: layer-1-passive
Layer 1 — Passive

Annotations

State bands colored by rig activity. Validity shading dims non-informative data. Artifact markers at state transitions. Health indicators compare current values against computed profiles. Present on every plot. No interaction required.

ARTWORK: layer-2-active
Layer 2 — Active

Alerting

Transition anomaly: settle time exceeds 2x the computed average. Relationship break: a correlation that held in DRILLING inverts or drops. State inconsistency: channel values contradict the detected rig state for more than 30 seconds.

ARTWORK: layer-3-interactive
Layer 3 — Interactive

Investigation

Point query: what is happening at this depth? Channel query: tell me everything about this channel. Interval query: summarize this 500-foot section. Structured responses with optional LLM narrative synthesis via local model.
