MPD COMMAND
===========

This is a software tool that computes the dollar value of
Managed Pressure Drilling for any well.

It answers the question operators always ask:
"What does MPD actually do for my well?"

The answer is in the numbers:
- How much formation damage does MPD prevent
- How many more barrels does the well produce
- How much drilling time and mud cost does MPD save
- What is the total dollar value vs the service cost

Every calculation is based on published SPE and IADC
equations. 28 verification tests pass at 99.1 out of 100.

To run it: double-click START_HERE.bat
